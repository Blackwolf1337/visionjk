Models

Pick a model, then right-click on the map.
Every model is placed as a misc_prop with physics of its own: a body with the shape of the model that falls, tips, can be shoved, thrown, stacked and stood on. Thrown hard at somebody it hurts. It is in the list of the World tab afterwards.

Map

Bot route

The waypoints the bots walk along, in the order of the trail: yellow from each one to the next, blue to the others it leads to. A click selects one. With Add on, a right-click on the map puts a new one there, behind the selected one or at the end.
The bots stand still from the first change until the route is saved: which waypoint leads to which is only worked out again by the save, and so is the blue.

server.cfg

The first save puts the file into the home path of the server (fs_homepath/<game>/server.cfg), which the engine reads before the one of the installation. The text before a save is kept as server.cfg.bak.
Executing sets the cvars of the file at once. Latched ones (most g_web*, sv_maxclients, the game type) take effect with the next map, and a line that changes the map does so.
The passwords in the file are shown as they are.

Bans

The addresses that may not connect (banIPs.txt of the server). A * stands for any number. "Ban" in the panel of a player puts his address here and kicks him.

Server load

One value a second, the last five minutes of this map. A frame of the game is the step of the game module alone, with the work of this panel in it, which the second line shows by itself: answering a browser is done in a frame. Fewer frames than sv_fps or a long wait for one mean the machine does not keep up.

Server log

The log of the game as the server writes it: who came and went, kills, chat, the commands of admins. The view starts with the last lines and follows the log as it grows. The whole file is games.log in the Files tab.

Files

Only these two folders, nothing above them. A click opens a folder or a text file, any other file is downloaded.
Changes go into the server folder only. Game modules and programs can be downloaded, not written, renamed or deleted. A new pk3 is found by the server with the next map.
