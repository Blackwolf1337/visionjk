# Security policy

## Supported versions

| Version | Gets fixes |
|---|---|
| Latest release (now 0.2.8) | Yes |
| Older releases | No |
| Dev builds (`vX.Y.Z-dev.N`) | Fixed by a newer dev build |

## Reporting a problem

Send a private message on Discord to the user `xleuiv`. Never report a security problem in a public issue or pull request.

Please include:

- the VisionJK version
- the platform (Windows or Linux) and the renderer
- the steps to reproduce it
- what an attacker gains from it

## What happens next

You get an answer. If the report holds, the fix goes into a release or a newer dev build, and you are told when it is out.
